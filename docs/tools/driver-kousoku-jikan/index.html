トラック・タクシー運転者の拘束時間と休息期間のチェック

始業・終業（トラックは運転時間も）を日ごとに入れると、改善基準告示（2024年4月から適用）の 1日の拘束時間（13時間・最大15時間）、休息期間（継続11時間が基本・9時間が下限）、 14時間を超えた回数、2日平均と2週の運転時間を判定します。 1日は「始業から24時間」なので、翌日の始業が早まった分は前日の1日にも入ります。この重なりも数えます。

時刻は 8:00・21:30 のように入れます（800 や 8 でも読みます）。終業が始業より前の時刻なら翌日の終業として数えます。 休みの日は「休」に印を。何も入れていない日は「休み」ではなく「分からない日」として扱い、その日が要る判定は出しません。

基準を超えたところ

—

始業と終業を入力してください。

日付勤務1日の拘束時間休息期間運転2日平均
    この結果は概算です。 改善基準告示（自動車運転者の労働時間等の改善のための基準）の原則の基準と、厚生労働省の施行通達・パンフレットの数え方を当てはめたものです。 特例（宿泊を伴う長距離貨物運送、分割休息、2人乗務、隔日勤務、フェリー、タクシーの車庫待ち等）や 予期し得ない事象への対応時間に当たる場合は、上限や数え方が変わります。 タクシーの隔日勤務はタクシー隔日勤務の拘束時間と休息期間のチェックで判定できます。 拘束時間は休憩・仮眠・荷待ちを含む始業から終業までの時間です。勤務の記録（運転日報・デジタコ）の時刻で確かめ、 判断に迷うときは、勤め先の運行管理者、最寄りの労働基準監督署、社会保険労務士などの専門家にご確認ください。

    この計算の根拠

    1日の拘束時間：13時間まで、延長しても最大15時間

    一日（始業時刻から起算して二十四時間をいう。以下同じ。）についての拘束時間は、十三時間を超えないものとし、当該拘束時間を延長する場合であっても、一日についての拘束時間の限度（以下「最大拘束時間」という。）は、十五時間とすること。

    （改善基準告示 第2条第1項第2号・タクシー日勤。トラックは第4条第1項第3号が同じ基準で、宿泊を伴う長距離貨物運送の週は2回まで16時間）

    拘束時間は「労働時間、休憩時間その他の使用者に拘束されている時間」（第2条第1項）で、休憩や仮眠、荷待ちも入ります。 1日は暦の日ではなく始業から24時間です。厚労省のパンフレットは、月曜 8:00〜21:00・火曜 6:00 始業のとき、 月曜から始まる1日は「月曜日の13時間だけではなく、火曜日の２時間もカウントした合計15時間」と説明しています。 火曜から始まる1日でも、その6:00〜8:00は「再度カウントする」ので、重なった時間は両方の日に入ります。

    14時間を超える回数：トラックは週2回、タクシー日勤は週3回まで（目安）

    当該回数については、１週間について２回以内を目安とすること。この場合において、１日の拘束時間が「14 時間」を超える日が連続することは望ましくないこと。

    （施行通達 基発1223第3号 第2の4(2)・トラック。タクシー日勤は第2の2(1)イで「１週間に３回以内を目安とすること」）

    告示は「十四時間を超える回数をできるだけ少なくするよう努める」と書いています。「1年」「1か月」「1週間」の区切りについて、厚労省のQ&A（1-3）は「事業場の就業規則や労使協定等で定めた期間の初日」が起算日になるとしています。このツールは1日目を起算日にして7日ごとに数えるので、1日目には勤め先の起算日を入れてください。

    休息期間：継続11時間が基本、9時間を下回らない

    勤務終了後、継続十一時間以上の休息期間を与えるよう努めることを基本とし、休息期間が継続九時間を下回らないものとすること。

    （改善基準告示 第2条第1項第4号・第4条第1項第5号）

    終業から次の始業までの時間です。9時間を下回ると基準違反、9時間以上11時間未満は違反ではありませんが、11時間以上を与えるよう努めるのが基本です。休息期間は始業から24時間以内に収まる必要はなく、拘束時間だけを24時間の中で確かめます（厚労省のQ&A 2-1・3-2）。

    運転時間（トラック）：2日平均9時間・2週平均44時間

    運転時間は、二日（始業時刻から起算して四十八時間をいう。次条において同じ。）を平均し一日当たり九時間、二週間を平均し一週間当たり四十四時間を超えないものとすること。（告示 第4条第1項第6号）

    次の①②のいずれもが「９時間」を超えた場合に、初めて違反と判断される。①特定日の運転時間（Ａ時間）と特定日の前日の運転時間（Ｂ時間）との平均、② 特定日の運転時間（Ａ時間）と特定日の翌日の運転時間（Ｃ時間）との平均（施行通達 第2の4(4)）

    たとえば10時間・9時間・9時間と運転した2日目は、前日との平均が9.5時間でも翌日との平均が9時間ちょうどなので違反になりません（パンフレットの例）。 厚労省のQ&A（3-6）は、特定日の前日の始業から48時間と、特定日の始業から48時間で、それぞれ1日あたりの平均をとると説明しています。 2週は「特定の日を起算日として２週間ごとに区切り」、合計が88時間を超えると違反です。このツールは1日目を起算日にします。 運転時間は勤務ごとに入れた値をその日の運転時間として数え、1日の拘束時間のように前日の24時間へ重ねて数え直すことはしていません（運転時間の重なりの数え方は、告示・通達・Q&A に見当たりません）。

    1か月の拘束時間：トラック284時間・タクシー日勤288時間

    1か月（原則として暦月）の拘束時間は、各勤務の始業から終業までを「そのまま合計」して比べます（パンフレット）。重なりは二重に数えません。 トラックは労使協定があれば年6か月まで310時間（年3,400時間以内）、タクシー日勤の車庫待ち等は300時間まで延長できます。 このツールは2週分の入力なので、1か月の判定はせず、入力した勤務の合計だけを示します。

    よくある質問

    休憩や荷待ちの時間は拘束時間から引けますか

    引けません。拘束時間は始業から終業までの全ての時間で、休憩・仮眠・荷待ち（手待ち時間）を含みます。引けるのは、事故・故障・災害・異常気象などの「予期し得ない事象への対応時間」を客観的な記録で確認できる場合の、1日の拘束時間・2日平均の運転時間・連続運転時間だけです（告示 第4条第3項）。

    15時間を超えた日があります。すぐに違反ですか

    原則の最大拘束時間は15時間です。トラックで、その週の運行がすべて450km以上の長距離貨物運送で、休息期間を住所地以外でとる場合は、週2回まで16時間にできます（第4条第1項第3号ただし書）。2人乗務・隔日勤務・フェリーなどの特例もあります。特例に当たらなければ、15時間を超えた日は基準を超えています。

    連続運転時間（4時間）は判定できますか

    できません。連続運転時間は、運転を始めてから中断（1回おおむね連続10分以上・合計30分以上）までの時間で、運転と中断の時刻が分単位で要ります。デジタコの記録で確かめてください。

    個人事業主のドライバーにも当てはまりますか

    告示の直接の対象は労働者です。ただし貨物自動車運送事業者は、国土交通大臣の告示で運転者の勤務時間・乗務時間を定めるよう求められ、その基準として改善基準告示が引用されているので、個人事業主の運転者にも実質的に守ることが求められています（施行通達 第2の1(5)）。
