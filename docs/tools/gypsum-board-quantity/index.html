この計算は概算です。 実際の枚数は下地の位置、開口部のおさまり、継目の割付方針、端材をどこまで使い回すかで変わります。 防火・準耐火・遮音などの性能が求められる部位は、仕様書で指定された工法・厚さ・留付間隔が優先されます。 最終的な数量と仕様は、施工店・設計者などの専門家にご確認ください。 計算結果にもとづく発注について責任を負いかねます。

なぜ「面積÷1枚の面積」ではいけないのか

石膏ボードの必要枚数を、延べ面積を1枚の面積で割って求める計算をよく見かけます。 これは理論上の下限であって、実際に張れる枚数ではありません。

たとえば 3640mm × 2730mm の面に 910×1820 のボード（3×6版）を張るとします。 面積で割ると 9.94㎡ ÷ 1.66㎡ ＝ ちょうど 6枚です。 ところが縦張りで実際に並べると、横に 4列（3640 ÷ 910）、縦に 2段（2730 ÷ 1820 を切り上げ）で 8枚必要になります。2枚の差は、2段目で余った部分が 幅の合わない細長い端材になるために生じます。

端材がまったく使えないわけではありませんが、寸法がまちまちなうえ、 継目の位置には制約があります（重ね張りでは上張りと下張りの継目を同じ位置にしない、など）。 足りないほうが困るので、このツールは割付で数えた枚数を主たる答えとし、 面積割りの値は比較用に並べて表示します。

長さを変えると枚数が大きく変わります

見落とされがちですが、ボードの長さを天井高に合わせると段継ぎが消えます。 天井高 2400mm の壁で比べると、次のようになります。

  • 910×1820（3×6版）… 2400mm に届かないので2段必要。6畳の壁4面で 28枚
  • 910×2420（3×8版）… 1枚で 1段。同じ部屋が 14枚

枚数が半分になるだけでなく、横方向の継目（ジョイント）そのものが無くなります。 継目はパテ処理の手間が増え、後からひび割れが出やすい箇所でもあります。 上のツールでボードの寸法を切り替えると、この差がそのまま数字で出ます。

留付具（ビス・釘）の間隔と本数

留付間隔は壁と天井で違い、工法によっても違います。 石膏ボード工業会の施工マニュアルでは次のように定められています（単位 mm・いずれも「以下」）。

部位・工法留付具周辺部一般部
壁：在来軸組工法・一般壁釘、ねじ200300
壁：在来軸組工法・耐力壁（告示仕様）釘150150
壁：枠組壁工法釘、ねじ100200
壁：鋼製下地ねじ200300
天井：在来軸組工法・一般釘、ねじ150200
天井：枠組壁工法・一般釘、ねじ150200
天井：鋼製下地ねじ150200

「周辺部」はボードの外周、「一般部」はその内側を通る下地材の上を指します。 外周は端から10mm程度内側で留めます。 本ツールはこの間隔と、入力された下地の間隔から本数を数えています。 切り欠いたボードは留め代が減るため、実際の本数はやや少なくなります （多めに見積もる側に倒しています）。

省令準耐火仕様は「1枚目／2枚目」で間隔が分かれ、下地に対する向きでも変わるため、 このツールでは扱っていません。該当する場合は下記の一次情報をご確認ください。

留付具の長さ

  • 木製下地に釘… ボード厚の 2.5〜3倍程度（厚12.5mmなら約31〜38mm）
  • 木製下地にねじ… ボード厚より 15mm 以上長いもの（厚12.5mmなら27.5mm以上）
  • 鋼製下地にねじ… 下地の裏面に 10mm 以上の余長が得られる長さ

よくある質問

開口部（窓・ドア）は差し引けますか

このツールでは差し引いていません。開口部のまわりは、継目が開口の角と重ならないように ボードを切り欠いて張るのが一般的で、切り取った部分が そのまま別の場所に使えるとは限らないためです。 掃き出し窓のように1列まるごと不要な範囲があるときは、 その面を左右に分けて2つの面として入力してください。

厚さは 9.5mm と 12.5mm のどちらを選べばよいですか

用途によります。一般的な石膏ボード（JIS A 6901 の GB-R）は、 メーカー各社の製品案内で 9.5mm が準不燃材料、12.5mm 以上が不燃材料として 扱われています。壁の下地に 12.5mm、天井に 9.5mm を使う例が多く見られますが、 必要な性能は部位と法令上の要求で決まるため、仕様書がある場合はそちらが優先されます。

ボードのサイズには何がありますか

工業会の資料では、代表製品の長さとして 910 / 1820 / 2420 / 2730mm、 幅として 455 / 606 / 910 / 1210mm が挙げられています。 普通石膏ボードで一般に流通しているのは 910×1820（3×6版）、910×2420（3×8版）、 910×2730（3×9版）です。上のツールではこの組み合わせを選べます。

2枚張り（重ね張り）のときは

枚数は単純に2倍になりますが、上張りと下張りの継目を同じ位置にしない 必要があります。割付をずらすぶん端材が増えるので、予備を見ておくと安全です。

ほかの材料の数量も出せますか

下地が終わったあとの仕上げについては、 壁紙・クロスの必要量と ペンキ・塗料の必要量を用意しています。 同じ部屋でも材料ごとに数え方の作法が反対になる点（開口部を引くか引かないか） も、それぞれのページで説明しています。
