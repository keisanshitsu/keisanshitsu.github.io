派遣の3年ルール（抵触日）の計算

派遣で働き始めた日を入れると、同じ課で最後に働ける日と抵触日（期間制限に抵触することとなる最初の日）を出します。 労働者派遣法の個人単位（第35条の3）と事業所単位（第40条の2）の両方を数え、早く来るほうを示します。 事業所単位の延長と意見聴取の期限、前の派遣との空白が3か月を超えて数え直しになるかも確かめられます。

あなたの派遣の形

個人単位（同じ課で3年まで）

派遣会社が変わっていても、同じ課で続けて働いているなら最初の日です。

同じ課での前の派遣（任意）

いちど途切れてから同じ課に戻ったときに入れます。空白が3か月を超えていなければ、前の派遣から続けて数えます。

事業所単位（派遣先の事業所で3年まで・任意）

分からなければ空のままで構いません。就業条件明示書に書かれた事業所単位の抵触日と見比べてください。

働き始めた日を入力してください。

区分起算日抵触日最後に働ける日
    この結果は概算です。 労働者派遣法の条文と厚生労働省の派遣先指針の定めを、民法の期間の数え方で日付に当てはめたものです。 条文や業務取扱要領には抵触日の日付の計算例が載っていないため、「開始日を1日目に数え、3年後の同じ日付が抵触日」という数え方は、このツールが民法から導いたものです。 組織単位（課）がどこまでかは名称ではなく実態で判断され、例外（有期プロジェクト・日数限定など）に当たるかにも条件があります。 正式な抵触日は、派遣会社から渡される就業条件明示書に書かれています（第34条）。 食い違うときや判断に迷うときは、派遣会社の担当者、都道府県労働局の需給調整事業の窓口、社会保険労務士などの専門家にご確認ください。

    この計算の根拠

    個人単位：同じ人を同じ課で3年まで（第35条の3・第40条の3）

    派遣元事業主は、派遣先の事業所その他派遣就業の場所における組織単位ごとの業務について、三年を超える期間継続して同一の派遣労働者に係る労働者派遣（第四十条の二第一項各号のいずれかに該当するものを除く。）を行つてはならない。

    （労働者派遣法 第35条の3。派遣先の側からも第40条の3 が同じことを定め、事業所単位を延長した場合も変わりません）

    同じ人が同じ課（組織単位）で働けるのは3年までで、個人単位には延長の手続がありません。 課が変われば、同じ事業所の中でも個人単位は新しく数えます。

    事業所単位：派遣先の事業所で3年まで、意見聴取で延長できる（第40条の2）

    派遣先は、当該派遣先の事業所その他派遣就業の場所ごとの業務について、派遣元事業主から派遣可能期間を超える期間継続して労働者派遣の役務の提供を受けてはならない。（第1項）

    前項の派遣可能期間（以下「派遣可能期間」という。）は、三年とする。（第2項）

    …労働者派遣の役務の提供が開始された日（この項の規定により派遣可能期間を延長した場合にあつては、当該延長前の派遣可能期間が経過した日）以後当該事業所その他派遣就業の場所ごとの業務について第一項の規定に抵触することとなる最初の日の一月前の日までの間（次項において「意見聴取期間」という。）に、厚生労働省令で定めるところにより、三年を限り、派遣可能期間を延長することができる。（第3項）

    事業所単位は、その事業所が最初に派遣を受け入れた日から数えます。派遣会社が変わっても数え直しにはなりません（奈良労働局の派遣先向け資料）。 派遣先は、抵触日の一月前の日までに過半数労働組合等の意見を聴けば、3年を限りに延長できます。異議が出たときの説明は、抵触日の前日までです（第40条の2第5項。業務取扱要領は「事業所単位の期間制限の抵触日の前日までに」と書いています）。

    3か月を超える空白で数え直し（派遣先指針 第2の14）

    派遣先は、労働者派遣の役務の提供を受けていた当該派遣先の事業所等における組織単位ごとの業務について、同一の派遣労働者に係る新たな労働者派遣の役務の提供を受ける場合には、当該新たな労働者派遣の開始と当該新たな労働者派遣の役務の受入れの直前に受け入れていた労働者派遣の終了との間の期間が３月を超えない場合には、当該派遣先は、当該新たな労働者派遣の役務の受入れの直前に受け入れていた労働者派遣から継続して労働者派遣の役務の提供を受けているものとみなすこと。

    （派遣先が講ずべき措置に関する指針 第2の14(4)。事業所単位は同じ形の(3)。(5)は延長の手続を避ける目的で3か月あけて受け入れ直すことを「趣旨に反する」としています）

    業務取扱要領も「就業の日と次回の就業の日との間の期間が３箇月以下であれば…継続して…みなす」と書いています（第7の6(4)イ）。 空白がちょうど3か月なら続けて数え、3か月を1日でも超えれば数え直しです。 たとえば3月31日に終わったなら、空白の3か月は4月1日〜6月30日なので、7月1日に始まれば継続、7月2日以後なら数え直しです。

    例外：期間制限がかからない派遣（第40条の2第1項各号）

    • 派遣会社に無期雇用されている派遣労働者（第1号）
    • 60歳以上の人（第2号・施行規則 第32条の4「六十歳以上の者とする。」）
    • 事業の開始・転換・拡大・縮小・廃止のための業務で、一定の期間内に完了することが予定されているもの（第3号イ）
    • 1か月の日数が派遣先の通常の労働者の所定労働日数に比べて相当程度少なく、厚生労働大臣の定める日数以下の業務（第3号ロ）
    • 産前産後休業・育児休業・介護休業などをする人の業務の代わり（第4号・第5号）

    日付の数え方（民法 第140条・第143条）

    日、週、月又は年によって期間を定めたときは、期間の初日は、算入しない。ただし、その期間が午前零時から始まるときは、この限りでない。（民法 第140条）

    週、月又は年の初めから期間を起算しないときは、その期間は、最後の週、月又は年においてその起算日に応当する日の前日に満了する。ただし、月又は年によって期間を定めた場合において、最後の月に応当する日がないときは、その月の末日に満了する。（同 第143条第2項）

    派遣は開始日の午前零時から始まるので、開始日を1日目に数えます。2026年4月1日に始めたなら、3年は2029年3月31日に満了し、抵触日はその翌日の2029年4月1日です。 2028年2月29日に始めたときは2031年2月に29日が無いので、2月28日に満了し、抵触日は3月1日です。 意見聴取期間の終わり（抵触日の一月前の日）は、前の月に同じ日付が無いとき（抵触日が3月31日など）その月の末日にしています。民法にさかのぼる向きの定めが無いため、期限を早めに見る側に倒しました。

    よくある質問

    抵触日に働いてはいけないのですか

    はい。抵触日は「期間制限に抵触することとなる最初の日」で、その日から同じ課（事業所単位なら事業所）で派遣として働くことはできません。 最後に働ける日は抵触日の前日です。抵触日以後も受け入れると、派遣先が派遣労働者に労働契約の申込みをしたものとみなされる制度があります（第40条の6）。

    3年たったら、どうなりますか

    同じ課で3年働く見込みがあり、本人が続けて働くことを希望しているときは、派遣会社は雇用安定措置を講じなければなりません（第30条第2項・施行規則 第25条）。 措置には、派遣先への直接雇用の依頼、新しい派遣先の提供、派遣会社での無期雇用などがあります。1年以上の見込みなら努力義務です（第30条第1項）。 別の課に移る・別の派遣先に移る・派遣会社に無期雇用される（例外に当たる）などで、働き続ける道があります。

    抵触日はどこに書いてありますか

    派遣会社は、派遣の前に、個人単位と事業所単位の両方の抵触日を本人に明示しなければなりません（第34条第1項第3号・第4号）。 派遣先は、派遣契約を結ぶ前に事業所単位の抵触日を派遣会社に書面などで通知します（第26条第4項）。就業条件明示書を確かめてください。

    派遣会社を変えれば、また3年働けますか

    同じ課で続けて働くなら、派遣会社を変えても期間はつながったままです。 個人単位について、業務取扱要領は空白が「３箇月以下であれば…継続して同一の派遣労働者に係る労働者派遣の役務の提供を受けているものとみなす。この場合、同一の派遣労働者について、派遣元事業主が異なる場合であっても同一の派遣労働者と評価される」と書いています（第7の6(4)イ）。 事業所単位についても、奈良労働局の派遣先向け資料は「派遣元が変わっても、その期間に影響は受けません。（リセットされません。）」と書いています。
