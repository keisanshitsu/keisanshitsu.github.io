駐車スペースの寸法計算

駐車スペースの間口・奥行と、車検証に載っている車の全長・全幅を入れると、並列・縦列に並べたときの余り・不足をcmで出します。 物差しは2つあります。車体がそのまま収まるか（車庫証明の「全体を収容」の目安）と、 国土交通省の指針の駐車ます（普通乗用車なら幅2.5m×長さ6.0m）で足りるか。あわせて、指針の枠で何台入るかを出します。

    この結果は概算です。 「車体が収まる」は車どうし・壁との隙間を0として判定しているので、収まると出てもドアの開け閉めや出し入れができるとは限りません。 車庫証明（自動車保管場所証明）の可否は、道路からの出入りや距離の要件も含めて警察署が判断します。 国土交通省の指針は公共の駐車場の設計の目安で、自宅の駐車スペースに義務として掛かるものではありません。 工事の計画は、外構の施工業者などの専門家にご確認ください。

    この計算の根拠

    物差し1: 車体がそのまま収まるか（車庫証明の目安）

    当該自動車が法令の規定により通行することができないこととされる道路以外の道路から当該自動車を支障なく出入させ、かつ、その全体を収容することができるものであること。（自動車の保管場所の確保等に関する法律施行令 第1条第2号）

    保管場所（車庫）は、車の全体を収容できることが要件の一つです。本ツールは車検証の全長・全幅をそのまま並べ、 スペースの内法に収まるかを見ています。並べ方によって次のように足し合わせます。

    並列: 必要な幅 ＝ 全幅の合計、必要な奥行 ＝ いちばん長い全長
    縦列: 必要な幅 ＝ いちばん広い全幅、必要な奥行 ＝ 全長の合計

    同じ条文の「支障なく出入させ」（前面の道路から出し入れできるか）や、第1号の「使用の本拠から2km以内」は寸法だけでは決まらないので、判定していません。

    物差し2: 国土交通省の指針の駐車ます

    駐車ますの大きさは、設計対象車両に応じて、表－２．４．１に示す値以上とすることを原則とする。（駐車場設計・施工指針 2.4.2）

    表-2.4.1 駐車ますの大きさ（長さ×幅員）: 軽自動車 3.6m×2.0m ／ 小型乗用車 5.0m×2.3m ／ 普通乗用車 6.0m×2.5m

    表-2.4.2 天井の有効高さ（車室）: 軽自動車 2.1m ／ 小型乗用車 2.1m ／ 普通乗用車 2.2m

    指針の枠は車体より一回り大きく、たとえば全幅1.70mの小型自動車なら枠の幅2.3mとの差の60cmが両脇に残ります。 ドアの開け閉めに何cm要るかには公的な数値が無いので、本ツールは「足りる・足りない」を言わず、残る幅を示すだけにしています。

    車の区分（軽・小型・普通）

    小型自動車: 長さ 4.70m以下・幅 1.70m以下・高さ 2.00m以下 ／ 軽自動車: 長さ 3.40m以下・幅 1.48m以下・高さ 2.00m以下（道路運送車両法施行規則 別表第一。排気量などの条件もあります）

    区分で「軽」「小型」を選ぶと、その上限の寸法が入ります。お手持ちの車の数値は車検証の「長さ」「幅」「高さ」で確認して書き換えてください。 上限を超える寸法を入れるとエラーになります。長さ・幅・高さのどれかが小型自動車の上限を超える車（軽自動車を除く）は「普通」を選び、寸法を入力してください（「普通」を選んだときに入る寸法は例です）。 指針の枠は、小型自動車に「小型乗用車」、普通自動車に「普通乗用車」の値を当てています。

    よくある質問

    2台並べるには幅が何m要りますか

    指針の枠で考えると、普通乗用車2台で 2.5m×2＝5.0m、小型自動車と軽なら 2.3m＋2.0m＝4.3mです。 車体だけなら小型自動車の上限（全幅1.70m）と軽の上限（1.48m）で3.18mですが、これでは車の間に隙間がありません。

    車庫証明は「指針の大きさ」が無いと取れませんか

    施行令の要件は「全体を収容することができる」ことで、指針の枠の大きさは要件として書かれていません。 ただし運用や必要書類は都道府県警察ごとに定められているので、申請先の警察署で確認してください。

    カーポートの屋根の高さはどれくらい要りますか

    車体が入るには全高より高ければ足りますが、指針の天井の有効高さは軽・小型で2.1m、普通で2.2mです。 カーポートを付けるときの建ぺい率の計算もあわせて確認してください。

    ほかの外まわりの計算もできますか

    駐車場を舗装するときの土間コンクリートの材料計算、 カーポートの建ぺい率計算、 物置を置くときの建築確認の要否と建ぺい率、 フェンスの枚数・柱の本数、 スロープの長さ計算があります。
