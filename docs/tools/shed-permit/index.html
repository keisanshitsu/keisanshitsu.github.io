物置の建築確認の要否と建ぺい率

地面に固定して使う物置は、屋根と壁があるので建築物です。建築確認（確認申請）が要らないのは、 自宅の敷地に置く（増築）・防火地域でも準防火地域でもない・床面積の合計が10㎡以内の3つがそろったときです。 1つでも欠けると、都市計画区域の中では面積が小さくても要ります。 場所と物置の寸法を入れると要否を判定し、置いたあとの建ぺい率・容積率と、上限まであと何㎡置けるかも出します。

確認が要らない3つの条件（建築基準法 第6条第2項）

    項目面積・割合
      この結果は概算です。 判定は建築基準法・同施行令の条文に基づきますが、小さな物置を建築物として扱うかどうかや、 増築か新築かの扱いの細部は特定行政庁（市区町村または都道府県の建築指導の担当）によって取扱いが異なることがあります。 確認が要らない場合でも、建ぺい率・容積率・構造などの規定は守る必要があります。 地区計画・建築協定、用途地域によって物置だけを空き地に置けない場合もあります。 実際の計画は、建築士・施工業者などの専門家、または特定行政庁の窓口にご確認ください。

      この判定の根拠

      物置も建築物になる

      建築物　土地に定着する工作物のうち、屋根及び柱若しくは壁を有するもの（これに類する構造のものを含む。）…（建築基準法 第2条第1号）

      地面やコンクリートに固定して、倉庫として使い続ける物置はこれに当たります。 ただし、奥行きが浅く人が中に入らない小さな物置を建築物として扱わない取扱いをしている自治体があります （例: 相模原市は奥行1m以下・高さ2.3m以下・床面積2㎡以内）。この基準は自治体ごとに違うので、本ツールでは判定していません。

      確認が要らないのは「防火地域外・増築・10㎡以内」

      前項の規定は、防火地域及び準防火地域外において建築物を増築し、改築し、又は移転しようとする場合で、その増築、改築又は移転に係る部分の床面積の合計が十平方メートル以内であるときについては、適用しない。（建築基準法 第6条第2項）

      家のある敷地に物置を置くのは増築、建物の無い空き地に物置だけを置くのは新築として扱われます （敷地は「一の建築物又は用途上不可分の関係にある二以上の建築物のある一団の土地」— 建築基準法施行令 第1条第1号）。 新築には10㎡の例外が無いので、空き地なら1㎡の物置でも確認が要ります。 2個以上を置くときは床面積の合計で判定します。

      区域の中では、例外に当たらなければ確認が要る

      都市計画区域・準都市計画区域などの中の建築物は、規模にかかわらず確認の対象です（建築基準法 第6条第1項第3号。準景観地区や、都道府県知事が指定する区域も含みます）。 防火地域・準防火地域は都市計画区域の中にだけ定められるので（都市計画法 第8条第1項第5号・第2項）、区域の外を選ぶと防火の項目は使いません。 区域の外では、平屋で200㎡以下の物置は第1号・第2号にも当たらないので、空き地に置く場合は確認が要りません。 区域の外で家のある敷地に10㎡を超える物置を置く場合は、家と合わせた規模で判断されるかが条文だけでは決まらないため、本ツールは「要確認」と表示します。

      確認が要らなくても、建ぺい率と容積率は守る

      建ぺい率 ＝（今ある建物の建築面積 ＋ 物置）÷ 敷地面積
      容積率 ＝（今ある建物の延べ面積 ＋ 物置）÷ 敷地面積

      建ぺい率は同じ敷地にある建物の建築面積の合計で計算します（建築基準法 第53条第1項）。 平屋の物置は建築面積にも延べ面積にも同じだけ加わるので、置ける残りは建ぺい率と容積率の残りの小さいほうです。 前の道が狭い敷地は容積率がさらに小さくなることがあります（セットバックの計算で確かめられます）。

      面積は本体の外寸で数えている

      正しくは壁の中心線で囲まれた面積（建築基準法施行令 第2条第1項第3号）ですが、本ツールは本体の外寸（間口×奥行）で数えます。 外寸のほうが少し大きいので、10㎡の判定は「要る」側、建ぺい率・容積率は「超える」側に出ます。 10㎡ぎりぎりの製品は、メーカーの寸法表の床面積で確かめてください。

      よくある質問

      10㎡以下の物置なら確認申請はいりませんか

      自宅の敷地で、防火地域・準防火地域でなければ要りません。 防火地域・準防火地域では面積にかかわらず要り、建物の無い空き地に置く場合も要ります。 防火地域・準防火地域かどうかは、市区町村の都市計画図（Web の地図サービスがある自治体も多い）で確認できます。

      物置を2つ置くとどうなりますか

      床面積の合計で判定します。例えば 2.2×1.6m（3.52㎡）と 2.6×2.5m（6.5㎡）は、1つずつなら10㎡以下ですが、 同時に置くと合計10.02㎡で10㎡を超えるので、確認が要ります。

      カーポートと一緒に置く場合は

      同時に建てる建物の床面積は合計して判定されることがあり、カーポートの扱いは特定行政庁によって分かれるため、本ツールの対象外です。 カーポートの建ぺい率はカーポートの建ぺい率計算で出せます。

      ほかの外まわりの計算もできますか

      土間コンクリートの材料計算（物置の下の土間にも）、 ブロック塀の計算、 フェンスの枚数・柱の本数、 防草シートの必要量があります。
