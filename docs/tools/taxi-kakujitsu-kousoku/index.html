タクシー隔日勤務の拘束時間と休息期間のチェック

隔日勤務の始業と終業を勤務ごとに入れると、改善基準告示（2024年4月から適用）の 2暦日の拘束時間（22時間まで）、前後の勤務との平均（21時間まで）、 休息期間（継続22時間が下限・24時間が基本）、1か月の拘束時間（262時間まで）を判定します。 平均は「前の勤務との平均」と「次の勤務との平均」がどちらも21時間を超えたときに違反になります。

勤務の始業した日と、始業・終業の時刻を入れます（7:00・3:30 のように。700 や 7 でも読みます）。 終業が始業より前の時刻なら翌日の終業として数えます。休日は入れなくてかまいません（休日の前後の勤務どうしで平均します）。 勤務は抜けなく入れてください。抜けがあると、平均と休息期間を正しく判定できません。

基準を超えたところ

—

勤務の日付・始業・終業を入力してください。

勤務拘束時間前後との平均休息期間
    この結果は概算です。 改善基準告示（自動車運転者の労働時間等の改善のための基準）第2条第2項の原則の基準と、厚生労働省の施行通達・Q&Aの数え方を当てはめたものです。 車庫待ち等（2暦日24時間までの延長）や予期し得ない事象への対応時間に当たる場合は、上限や数え方が変わります。 拘束時間は休憩・仮眠を含む始業から終業までの時間です。乗務記録の時刻で確かめ、 判断に迷うときは、勤め先の運行管理者、最寄りの労働基準監督署、社会保険労務士などの専門家にご確認ください。

    この計算の根拠

    隔日勤務とは

    隔日勤務（始業及び終業の時刻が同一の日に属さない業務をいう。以下同じ。）

    （改善基準告示 第2条第1項）

    2労働日の勤務を1勤務にまとめて行うものです。厚労省のQ&A（2-3）は、7時に出勤して28時（翌4時）に退勤する勤務は隔日勤務に当たる一方、 22時に出勤して28時に退勤する勤務は「単なる夜間勤務として日勤の拘束時間の上限が適用される」としています。 反対に、午前1時に出勤して午後10時に退勤するように始業と終業が同じ日になる勤務でも、実態が2労働日をまとめた勤務なら隔日勤務の規定を適用してよいとされています（Q&A 追補 2-3-2）。 日勤の基準はトラック・タクシー運転者の拘束時間と休息期間のチェックで判定できます。 歩合給が最低賃金を下回っていないかは歩合給の最低賃金チェックで確かめられます。

    2暦日の拘束時間：22時間まで、2回の平均は21時間まで

    二暦日についての拘束時間は、二十二時間を超えないものとし、かつ、二回の隔日勤務を平均し隔日勤務一回当たり二十一時間を超えないものとすること。

    （改善基準告示 第2条第2項第2号）

    次の①②のいずれもが「21 時間」を超えた場合に、初めて違反と判断される。①特定の隔日勤務の拘束時間（Ａ時間）と、特定の隔日勤務の前の隔日勤務の拘束時間（Ｂ時間）との平均、②特定の隔日勤務の拘束時間（Ａ時間）と特定の隔日勤務の次の隔日勤務の拘束時間（Ｃ時間）との平均

    （施行通達 基発1223第3号 第2の2(2)イ）

    拘束時間は「労働時間、休憩時間その他の使用者に拘束されている時間」（第2条第1項）で、休憩や仮眠も入ります。 1回の勤務が22時間を超えると、それだけで基準を超えます。平均は、その勤務と前の勤務、その勤務と次の勤務の2通りで計算し、 どちらも21時間を超えたときだけ違反です。どちらか一方が21時間以下なら違反ではありません。 間に休日があっても、休日の前後の2回で平均します。厚労省のQ&A（2-4）は、22時間・22時間・休日・22時間の勤務で、 2回目は前との平均も次との平均も22時間なので違反になると説明しています（このページの最初の例です）。 このツールは、前の勤務か次の勤務が入っていない勤務の平均を「判定できない」と表示し、合格にはしません。

    休息期間：継続24時間が基本、22時間を下回らない

    勤務終了後、継続二十四時間以上の休息期間を与えるよう努めることを基本とし、休息期間が継続二十二時間を下回らないものとすること。

    （改善基準告示 第2条第2項第4号）

    終業から次の勤務の始業までの時間です。22時間を下回ると基準違反、22時間以上24時間未満は違反ではありませんが、24時間以上を与えるよう努めるのが基本です。施行通達は、下限の22時間を守るだけでなく24時間以上が確保されるよう自主的な改善を「特に要請」しています。

    1か月の拘束時間：262時間（労使協定で270時間）

    拘束時間は、一箇月について二百六十二時間を超えないものとすること。ただし、地域的事情その他の特別の事情がある場合において、労使協定により、一年について六箇月までは、一箇月の拘束時間を二百七十時間まで延長することができるものとする。

    （改善基準告示 第2条第2項第1号）

    入力した勤務の拘束時間（始業から終業まで）をそのまま合計して比べます。1か月の区切りは、勤め先の就業規則や労使協定で定めた期間の初日が起算日です（Q&A 1-3）。 月をまたぐ勤務をどちらの月に数えるかは、告示・通達・Q&Aに定めが見当たりません。勤め先の数え方で、1か月分の勤務をすべて入れてください。 合計が262時間以下でも、抜けた勤務があれば増えるので、このツールは「基準内」とは表示せず残りの時間を示します。 最初と最後の勤務の始業日が31日以上離れているときは、1か月を超える範囲とみなして判定しません。

    2024年3月までとの違い

    改正前は、2暦日の拘束時間が21時間まで、休息期間が継続20時間以上でした。2024年4月からは、2暦日22時間まで（かつ2回の平均21時間まで）、休息期間は継続22時間が下限・24時間が基本です。 1か月の262時間（労使協定で270時間）は変わっていません。このツールは2024年4月1日以降の勤務だけを判定します。

    よくある質問

    休憩や仮眠の時間は拘束時間から引けますか

    引けません。拘束時間は始業から終業までの全ての時間で、休憩・仮眠を含みます。引けるのは、事故・故障・災害・異常気象などの「予期し得ない事象への対応時間」を客観的な記録で確認できる場合の、2暦日の拘束時間だけです（告示 第2条第3項）。その場合でも、対応時間を含めて22時間を超えたときは、勤務終了後に継続24時間以上の休息期間が要ります。1か月の拘束時間からは引けません。

    22時間を超えた勤務があります。すぐに違反ですか

    原則は22時間までです。車庫待ち等（人口30万人以上の都市に所在しない事業場で、流し営業がほとんどでなく、夜間4時間以上の仮眠が確保される実態など）の運転者は、夜間4時間以上の仮眠を与え、労使協定で1か月7回以内の回数を定めた場合に、2暦日の拘束時間を24時間まで延長できます（第2条第2項第3号）。これに当たらなければ、22時間を超えた勤務は基準を超えています。

    日勤と隔日勤務が混ざっています

    頻繁に勤務態様を変えることは認められていません。当分の間、1か月の拘束時間が262時間以内、日勤の勤務の拘束時間が15時間以内、日勤の後に11時間以上の休息期間、休日労働は合わせて2週間に1回まで、を満たせば違反にはならないとされています（Q&A 2-2）。このツールは隔日勤務だけを判定します。

    休日に出勤した日があります

    休日労働は2週間について1回までで、休日労働によって拘束時間の上限を超えることもできません（第2条第4項）。このツールは休日労働の回数は判定していません。
